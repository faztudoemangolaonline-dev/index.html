# Faz Tudo Tecnologia IPTV

Aplicação Flutter para Android e Windows.

O workflow `.github/workflows/build-faztudo-iptv.yml` executa testes do núcleo IPTV e compila os APKs Android por arquitetura e a versão Windows. Os ficheiros são publicados como artefactos temporários do GitHub Actions.

A compilação só deve ser considerada entregue depois de o workflow terminar com sucesso e os artefactos serem descarregados e verificados.
